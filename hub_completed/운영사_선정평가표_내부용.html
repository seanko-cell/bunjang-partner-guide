📋 활용 안내

  1. 섹션 1 필수 요건에서 Pass/Fail 선택. 하나라도 Fail이면 해당 업체는 평가 제외.
  2. 섹션 2 배송 요율: 핸들링비용 + 지역별 운임 입력 → 정규화 점수 자동 산출. 핸들링비용은 계약 바인딩 확정값.
  3. 섹션 3 수수료율은 계약 바인딩 확정값, 나머지는 선정 참고 지표.
  4. 섹션 4에서 종합 점수 및 판정 확인. 70점↑ 선정 검토 / 60점 미만 탈락.

📋 활용 안내

  1. 각 운영사별 월간 KPI 실측값 입력 → 점수 자동 계산.
  2. 클레임 미해결 건수: 건당 -1점 / 차지백 자료 미제출: 건당 -2점 자동 차감.
  3. 노출 순위 가중치: KPI 40% + 수수료율 30% + 배송 요율 30%
